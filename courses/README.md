# courses/

The vault. Finished units are filed here at `courses/<course>/<code>-<slug>.md` with the front-matter header of `docs/method.md` §7, and the vault is the source of every course: `kit/build.py` reads the units from here, and a unit is written when its file is here with front matter; there is no second copy.

Each course folder also holds `course.toml`, the course's entry (S-DEC1, 20 Nov 2026): the keys `kit/courses.py` reads for it, found by folder. A new course is a new folder with its `course.toml`; `catalog.toml` at the repo root holds the tracks, the planned courses and the order.

- `brand-ai/`, `ux/`: the markdown courses' units (A5).
- `_template/`: the pack of a new markdown course (S-DEC2, 20 Nov 2026), with ⟨…⟩ placeholders: copied to `courses/<slug>/` by the `new-course` skill; `kit/courses.py` skips a folder whose name starts with `_`.
- `greece/` (78 reports) and `rome/` (79): Personal Mythology, every report in Markdown since P71-3 (1 November 2026), converted by script from the kit's HTML fragments with no word changed (`docs/p71-3.md`). The forms a report uses (dispute boxes, the Self-test's answers, ```` ```tree ```` and ```` ```viz ```` blocks) are in `kit/AGENT-SPEC.md`; `kit/mdcourse.py` (`history_html`) renders them and `kit/vault.py` finds a report by its id. A history report's front matter gives the model that wrote it; its review status stays in the course's `inputs/provenance.json`, and its curated sources in `<course>/bibliography/r-<id>.md`. The course's other inputs are in its folder too, named by its `course.toml` (S-DEC5, 20 Nov 2026): `inputs/` (the syllabus, `prompts-<course>.json`, `provenance.json`) and `bibliography/` (the curated `r-<id>.md` and `biblio.py`'s `unit-<n>.md`); the vault globs read only the folder's top level, so neither subfolder is taken for a report.
