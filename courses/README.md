# courses/

The vault. Finished units are filed here at `courses/<course>/<code>-<slug>.md` with the front-matter header of `docs/method.md` §7. For a markdown course (Brand + AI) the vault is the source: `kit/build.py` reads the units from here (A5), and a unit is written when its file is here with front matter; there is no second copy. `greece/` and `rome/` receive new modules only; the 137 reports written before 28 October 2026 live in `kit/` and are not re-filed.
