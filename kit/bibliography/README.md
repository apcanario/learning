# Bibliography

One file per unit and course (`<course>/unit-<n>.md`), regenerated by `build.py` through `biblio.py` from the citations inside the reports: ancient works with their locators, authors cited by bare locator, modern works with title and year, corpora and inscriptions, per report. Machine-extracted, so a check aid rather than a finished bibliography; where a report has a curated `r-<id>.md` beside these (written by its writer or a later pass), the unit file links to it. Kept so that every claim can be re-checked against its source later.
