No figure fails, so there are no fail details. In every figure the longest bar and its value are whole in the first frame at both widths. Nothing is clipped, every label belongs to its own bar, and dark and light are both readable.

One style point recurs (rm01, rm23, rm54, rm115): when a value is printed past the end of its coloured bar but the grey track goes on, the text can run over the track's end, so the background changes partway through a word or number. It is readable everywhere, so it is not a fault. If you want it tidied, the value text should sit wholly inside the track or wholly beyond it.
