## Design

- `private_terms.folders(c)`: the top-level folders of a built site holding a course's split pages. build.py `split()` writes a page to `<data-ctx>/`: a markdown course's `<prefix or id>-<key>` per sub-course (build.py `md_courses`: `brand-a`, `brand-b`, `supply-chain-execution-sce`), a history course's `<id>` (`greece`). The row's `<home>-*/` is read as these exact names: `brand-ai`'s home id is `brand-ai` but its folders are `brand-a/`, `brand-b/` (prefix `brand`), so a `<home_id>-*` glob would miss them.
- P-DEC10: `edition_files(name)` puts every file under a folder of a held course with `dated_lists` into `DATED`, as `files()` does for academy. `scan()` then treats them as academy's run does. `python3 kit/private_terms.py --edition <name>` gets the same, since it calls `edition_files`.
- P-DEC13: `edition_files(name, skip=ids)` leaves out the files under the folders of the given courses; root files (`index.html`, `new.html`, `viz-examples.html`) and every other folder stay. In verify.py:
  - default edition (academy): unchanged (`private_terms.check()`).
  - an edition holding only private courses (greece): unchanged, same message, not checked. Reading taken: the row says "mixed edition", and scanning greece's root files would fail today (12 hits of the owner's first name in `index.html`, from theme.css comments, which the academy brand keeps: `strip_comments = false`). That would be an output change to `verify.py --edition greece`.
  - a mixed edition: scan `edition_files(EDITION, skip=PRIVATE)` and print a new line naming the private courses and their skipped folders, before the count line:
    `private terms: edition <name> holds a private course (<ids>), which names its owner; its pages are not checked (<folders>), every other file of the edition is`
  - an edition with no private course: as before, with P-DEC10's DATED.
- The CLI `--edition` still scans every file of the edition (its documented contract); only verify.py skips.
- Build output: none changed (baseline clean below).
